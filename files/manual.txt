ОБЪЕКТ: СТАНЦИЯ МОНИТОРИНГА B-12
СТАТУС: ТЕСТОВЫЙ РЕЖИМ
----------------------------------------------------------------

ВНИМАНИЕ: Данный терминал является узлом прямого доступа к 
сегменту VOID. Несанкционированное использование карается 
согласно протоколу "РЕЗОНАНС-0".

[ОСНОВНЫЕ КОМАНДЫ]:
- help      : Список доступных системных модулей.
- status    : Диагностика состояния узла и уровня сигнала.
- ls / dir  : Просмотр содержимого текущей директории.
- get [id]  : Загрузка зашифрованных данных (требуется CLEARANCE).
- login     : Переход в режим авторизации.
- report    : Связь с оператором поддержки.
- hint      : Получити текущий ответ от оператора поддержки(CTRL+F5 required)

[ЗАМЕТКИ ИНЖЕНЕРА (Графит)]:
-  Система авторизации теперь динамическая. Если забыл ключ — 
   ищи в отчетах СБ. Они помешаны на математических методах 
   генерации (см. Gauss/Determinant).
